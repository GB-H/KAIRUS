# KAIRUS

**KAIRUS** e um sistema de inteligencia artificial construido do zero com Python e FastAPI.

## Status

**Versao:** 0.3.0  
**Status:** Em desenvolvimento ativo

## Funcionalidades

- Conversacao inteligente com reconhecimento de 17 intencoes
- Memoria de curto prazo (RAM) e longo prazo (SQLite)
- Persistencia de conversas — sobrevive a reinicios
- Sistema de ferramentas/plugins extensivel
- Calculadora matematica integrada
- Data e hora em tempo real
- Contador de texto
- Historico de conversas na sidebar
- Interface escura responsiva com animacoes
- Rate limiting (30 req/min por IP)
- Sanitizacao de input contra XSS
- 101+ testes automatizados com pytest
